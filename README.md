# ASD_Detection_Using_Eye_Tracker
The primary goal is to create a reliable predictive tool that can act as a screening mechanism, not a diagnostic one. It aims to identify individuals toddlers  who are at a high risk for ASD, flagging them for a comprehensive evaluation by a qualified healthcare professional.
